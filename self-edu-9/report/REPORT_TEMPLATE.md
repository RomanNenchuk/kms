## 3. Датасет і запити

- Вузли: Airport 60, Airline 12, Aircraft 120, Flight 700 (разом **892**). Ребра ≈ 3438.
- LPG-схема: `(Flight)-[:DEPARTS_FROM|ARRIVES_AT]->(Airport)`, `(Flight)-[:OPERATED_BY]->(Airline)`,
  `(Flight)-[:USES]->(Aircraft)`, `(Airline)-[:OWNS]->(Aircraft)`, `(Airport)-[:ROUTE]->(Airport)`.
- RDF-схема: ті самі сутності й предикати (`ex:departsFrom`, `ex:arrivesAt`, `ex:operatedBy`, `ex:uses`, `ex:owns`, `ex:route`).

| Запит | Що перевіряє |
|---|---|
| Q1 | Пошук за індексованою властивістю + 1 hop + сортування |
| Q2 | Join через ребро + агрегація (рейсів на авіакомпанію) |
| Q3 | Multi-hop шаблон «рейс → пересадка → рейс» з числовими умовами |
| Q4 | Досяжність за ≤ 3 hops (variable-length path) |
| Q5 | Глобальна агрегація по двох типах ребер + top-k |

Тексти запитів: у `src/queries.py` (вставити в додаток до звіту).

## 7. Декларація використання генеративного ШІ

- **Модель:** Claude Sonnet 5.5 (Anthropic).
- **Призначення:** налаштування середовища (Docker Compose), генератор датасету, скрипти завантаження й
  вимірювання; переклад запитів Cypher ↔ SPARQL.
- **Приклад запиту (Q3, Cypher → SPARQL):** `MATCH (:Airport {code:'WAW'})<-[:DEPARTS_FROM]-(f1)-[:ARRIVES_AT]->(m)<-[:DEPARTS_FROM]-(f2)-[:ARRIVES_AT]->(:Airport {code:'CPH'}) …`
  → SPARQL із `?f1 ex:departsFrom ?o ; ex:arrivesAt ?m . ?f2 ex:departsFrom ?m ; ex:arrivesAt ?d`.
- **Як перевірено:** правильні відповіді Q1–Q5 пораховано незалежно чистим Python (оракул); результати
  кожного сховища порівнюються з ним рядок у рядок (`bench.py`); SPARQL додатково перевірено локально на rdflib.
