# Синтетичні взаємодії (ЛР 16)
Згенеровано `scripts/gen_interactions.py`, seed=42. **Дані синтетичні, персональних даних немає.**
- Період 2026-09-01..2026-11-14; часове розбиття: train < 2026-10-26 ≤ test. Події `view` — негативні/нейтральні; релевантні: `open`, `save`, `helpful`.
- Користувачі: 56 «теплих» (є історія в train) і 8 «холодних» (приєдналися після cutoff). Документи: 36, з них 4 нових (з'являються після cutoff).
- Модель вподобань: роль + експозиція авіакомпанії до ризиків графа (rel_affected_by × rel_operated_by) + шум; 10 % випадкових кліків; популярність Zipf.
- Метадані `verified`, `last_reviewed`, `published_at`, рівні доступу користувачів — синтетичні (для демонстрації фільтрів). `sensitivity` документів — з `data/kb/sensitivity_overrides.json`.
- Зв'язок документ—тема і роль—тема — вручну в `reco/taxonomy.py` (V1).
