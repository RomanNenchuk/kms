# Результат 5. Text-to-SQL та аналітична панель

## 1. Реалізація
Файли: `text2sql/pipeline.py` (конвеєр), `text2sql/llm.py` (клієнт Gemini, Replay), `text2sql/evaluate.py` (оцінка), `tests/t2sql.jsonl` (16 питань: 12 аналітичних з еталонним SQL і 4 небезпечні), `dashboard/build.py`.

| Вимога C1 | Реалізація |
|---|---|
| Семантичний контекст | схема з БД + метрики/виміри з `metrics.yml` у системній підказці (версія підказки `v1`) |
| AST-перевірка (лише SELECT) | `validate()` на sqlglot, whitelist таблиць, заборона файлових функцій |
| Read-only | `duckdb.connect(read_only=True)` + `enable_external_access=false` |
| LIMIT | примусово додається / обмежується до 1000 |
| Тайм-аут | 10 с (`threading.Timer` + `con.interrupt`), перед виконанням `EXPLAIN` |
