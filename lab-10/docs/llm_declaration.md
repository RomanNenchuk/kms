# Декларація використання генеративного ШІ

- **Інструмент:** Gemini (`gemini-3.5-flash-lite`) через Google AI Studio API; 162 виклики, усі записані в `llm_log/` (дата, модель, temperature, seed=42, версія підказки, сирий вихід, рішення людини). Підсумок: `docs/llm_protocol.md`.
- **Призначення:**
  1. генерація кандидатів тестових запитів і речень-доказів зі статей корпусу (`chunkq-v1`, `q-gen-v2`, `gold-gen-v1`);
  2. переклад 20 запитів українською для порівняння за мовою (`translate-v1`);
  3. другий розмітник релевантності для обчислення κ (`kappa-v1`, temperature 0).
- **Приклад запиту:** «Read the passage and write ONE question ... "evidence" must be ONE short sentence copied EXACTLY from the passage...» (повні підказки в `llm_log/`).
- **Як перевірено:** (1) програмно: речення-доказ має бути точною цитатою з тексту, інакше кандидат відкидається; (2) вручну: кожен кандидат переглянуто, частину виправлено (`review_note` у `eval/*.jsonl`), 4 відхилено з поясненням (`claims/claims.csv`); (3) розмітка для κ виконана людиною наосліп, до порівняння з Gemini; (4) частка підтверджених тверджень 94% (див. `docs/llm_protocol.md`).
- **Обмеження:** Gemini — єдиний другий розмітник, тому κ показує згоду людини з моделлю; запити на запити без відповіді відібрано вручну за фрагментами BM25, повної відсутності відповіді в корпусі це не доводить.
- Ключі API не зберігаються в коді (`.env` у `.gitignore`); персональні дані не використовувалися.
