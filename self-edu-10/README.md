# СР10 — експеримент з embeddings (авіаційні перевезення)

Корпус і золота розмітка взяті з ЛР 10: 795 фрагментів із 36 статей англійської Вікіпедії, 33 запити з реченням-доказом
(20 paraphrase, 9 keyword, 4 multistep). Запити без відповіді (10) не беруться: для них recall/MRR не визначені.

## Запуск (Ubuntu, venv)
```bash
bash setup.sh                       # venv + CPU-torch + sentence-transformers + моделі
source .venv/bin/activate
python src/run_experiment.py --with-baseline
```
`--with-baseline` додає лексичний baseline (char n-gram) як нижню межу; серед ≥ 3 моделей він не рахується.
Перевірка без моделей: `python src/run_experiment.py --dry-run`. Docker (опційно, не тестувалось): див. `Dockerfile`.

## Моделі (`models.json`)
`e5-small-multi` і `minilm-multi` — як у ЛР 10; `minilm-en` (all-MiniLM-L6-v2, лише англійська) — нова, контраст за мовою;
`bge-m3` — опційна (вимкнена, ~2.3 ГБ).

## Сценарії
| Сценарій | Що перевіряє |
|---|---|
| `en->en` | основна якість |
| `en_para->en` | стійкість до перефразування (вимога про генеративний ШІ) |
| `uk->en` | українські запити до англійського корпусу — вплив мови |

## Що вийде в `results/`
| Файл | Для чого |
|---|---|
| `results.md` | таблиці для звіту: якість, затримка, індекс, мова, типи запитів, обрізання, нормалізація (C1, C2, C4) |
| `disagreements_en-en.md`, `disagreements_uk-en.md` | запити, де моделі розходяться; **пояснення дописуєш сам** (C3) |
| `summary.csv`, `per_query.csv` | сирі числа й ранги |
| `run_meta.json` | CPU, версії бібліотек |

## Відмінності від таблиці в ЛР 10 (чому цифри не збігаються)
- Тут пошук по 795 фрагментах корпусу напряму (точний cosine), у ЛР 10 — HNSW по hierarchical-chunking (2383 child-фрагменти з батьківським контекстом).
- 33 запити замість 20 (додано keyword і multistep). 20 paraphrase-запитів раніше використовувались для вибору моделі — для них оцінка оптимістичніша.

## Що лишається зробити вручну
1. **Перевірити згенероване ШІ в цій роботі:** українські переклади q21–q33 і всі 33 англійські перефразування `en_para` (у `data/queries.jsonl` позначені `ПОТРЕБУЄ перевірки людиною`; переклади q01–q20 уже перевірені в ЛР 10).
2. Дописати пояснення до ≥ 5 розбіжностей.
3. Заповнити `report/report_template.md`: висновок (мова, домен, вартість), декларацію ШІ, самоперевірку.
